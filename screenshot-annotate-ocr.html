How to

Use the screenshot and ocr in 4 steps

  1. 1

    Get an image

    Capture the screen or an area, upload a file, or paste with Ctrl+V.

  2. 2

    Mark it up

    Use the tools to add arrows, boxes, circles, text and blur. Crop if you need to.

  3. 3

    Copy text if you need it

    Press Extract text. Draw a box first to read only that part.

  4. 4

    Save

    Choose a format and download, or copy the picture to your clipboard.

Good to know

  • Capturing the screen needs a desktop browser. Uploading and pasting images works on phones too.
  • Text extraction downloads its language data the first time. Use it once while online and it works offline after that.
  • OCR is best on clear, printed text. Handwriting and tiny text may come out wrong.

FAQ

Questions about the screenshot and ocr

How do I copy text from a screenshot?

Load the image and press Extract text. You can draw a box first to read only part of it, then copy the result.

Does the OCR upload my image?

No. The text is read in your browser. Only the OCR language data is downloaded the first time.

Can I blur part of a screenshot?

Yes. Use the blur tool on the area, then save the image.

Which image formats can I save?

PNG, JPG, WEBP and BMP.

Does it work on a phone?

Uploading, annotating and converting work. Screen capture needs a desktop browser.
